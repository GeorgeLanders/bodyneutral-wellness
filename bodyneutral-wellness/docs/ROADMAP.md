# Roadmap

## Phase 1: Stabilize MVP

- Visual QA every screen on emulator and physical device.
- Fix text clipping and spacing issues.
- Add Privacy and Safety screen.
- Add medical, crisis, AI, and weight-management disclaimers.
- Add onboarding consent for AI proxy use.
- Polish app icon and splash experience.
- Confirm all videos render and controls work.

## Phase 2: Personalization

- Better onboarding segmentation:
  - Body confidence.
  - Weight management.
  - Strength and stamina.
  - Stress reset.
  - Mobility.
  - Mindful nourishment.
- Personalized Daily Plan:
  - One movement suggestion.
  - One nourish suggestion.
  - One mindset prompt.
  - One hydration/rest habit.
  - One optional weight-management action.
- Improve recommendation feedback:
  - More granular reasons.
  - Avoid repeated Not today suggestions for a few days.
  - Add "show me more like this."

## Phase 3: Trust And Safety

- Privacy policy URL.
- Data export.
- Journal lock.
- Local-only mode.
- Crisis resource screen.
- AI response safety filters.
- Backend rate limits.
- Minimal server logging.

## Phase 4: Beta

- Closed testing with 20 to 50 users.
- In-app feedback form.
- Crash monitoring.
- Analytics with privacy review.
- Play Store listing draft.
- Screenshot generation.

## Phase 5: Launch

- Public Play Store release.
- App website or landing page.
- Support email.
- Press/community outreach.
- Social content around shame-free wellness.

## Phase 6: Growth

- Premium guided plans.
- More movement video packs.
- Audio grounding sessions.
- Weekly AI reflection summaries.
- Optional wearable integrations.
- Community moderation tools.
- Coach personalization with stronger privacy controls.
